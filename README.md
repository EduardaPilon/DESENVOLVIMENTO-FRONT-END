# DESENVOLVIMENTO-FRONT-END

Trabalho da matéria de Desenvolvimento Front-End.

## Gerenciador de Tarefas Acadêmicas

Aplicação web desenvolvida para gerenciamento e visualização de tarefas acadêmicas.

### Funcionalidades

- Busca de tarefas por título;
- Filtro por status;
- Filtro por prioridade;
- Ordenação por prazo;
- Botão para limpar os filtros;
- Carregamento dos dados através de arquivo JSON;
- Tratamento dos estados de carregamento, sucesso, erro e vazio.
